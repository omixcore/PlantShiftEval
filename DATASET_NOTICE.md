# Dataset attribution and scope

PlantVillage images are attributed to Sharada P. Mohanty, David P. Hughes and Marcel Salathé; cite *Using Deep Learning for Image-Based Plant Disease Detection*, Frontiers in Plant Science 7:1419 (2016), DOI 10.3389/fpls.2016.01419. The canonical `mohanty/PlantVillage` dataset card at revision `9e97599868962bd0079b8db4b7f1efa9185fa1e7` declares CC BY-SA 3.0. The `GVJahnavi/Plant_village_subset` card omits a license; all 14,238 of its image bytes were matched to original PlantVillage Git blobs. Processed PlantVillage image caches remain subject to the original image license and attribution/share-alike terms; model/code licensing is a separate matter.

PlantDoc is attributed to Davinder Singh, Naman Jain, Pranjali Jain, Pratik Kayal, Sudhakar Kumawat and Nipun Batra; cite *PlantDoc: A Dataset for Visual Plant Disease Detection*, CoDS COMAD 2020, pp. 249–253, DOI 10.1145/3371158.3371196. The upstream `pratikkayal/PlantDoc-Object-Detection-Dataset` and `agyaatcoder/PlantDoc` card declare CC BY 4.0. The pinned mirror contains 2,342 training and 236 test images before the study's mapping/filtering.

No raw image files are committed to this repository. Workflow artifacts containing resized image caches include this notice. Changes include resizing, category mapping, removal of overlap/similarity candidates, and internal validation assignment. These are study processing choices, not endorsements by the data authors. `provenance/datasets.json` pins the exact downloads and SHA-256 values. The currently recovered mirror is suitable for a new, explicitly versioned study; file identity with undocumented historical local inputs is not established.
